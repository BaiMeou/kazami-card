# 全球隐世格局

## 三层治理结构

全球隐世由三层互不隶属的体系共同支撑，没有任何一方能单独控制局面。

**表层：S.C.B（特别对策局）**。人类官方的全球超自然管理机构，日内瓦总部，五大区域指挥部（亚太、欧洲、美洲、非洲、中东），直属联合国安理会秘密委员会。处理的是"人和妖之间的关系"——管控、清洗、谈判、必要时的武力。

**中层：各区域隐世势力**。每个地区有自己的异类社会和人类超凡传承，形态千差万别——日本的八大势力、华夏的玄门宗门、欧洲的血族领地和结社、北美的移民混居。处理的是"隐世内部的事"——地盘、规矩、传承、利益分配。

**深层：织网者**。认知滤网的维护组织，超然于一切政治之上，十二个维护区各设一名织手。处理的是"世界底层的事"——滤网不塌，其他一切才有意义。

三层之间靠《昆仑公约》维系：公约承认各方在各自层面的管辖权，同时把"维持认知滤网"列为凌驾一切的共同义务。

## 全球维护区划分

织网者将全球划分为十二个维护区，每区对应一枚一级意识锚，设织手一名，编制上限七人。一级锚之间通过主灵脉干网互联，1024枚各级意识锚构成覆盖全球的认知干扰网络。

| 维护区 | 覆盖范围 | 区域特征 |
|--------|----------|----------|
| 东亚一区 | 中国大陆腹地 | 玄门势力最强区域，昆仑总部锚定于此区灵脉网络 |
| 东亚二区 | 中国东北、朝鲜半岛、俄罗斯远东 | 多族混居带，边境灵脉管理常年扯皮 |
| 东亚三区 | 日本列岛 | 全球灵脉密度最高区域之一，风见市所在，负荷为全球均值三倍 |
| 东南亚区 | 中南半岛、马来群岛、菲律宾 | 泛灵传统最盛，人妖边界天然模糊 |
| 南亚区 | 印度次大陆 | 苦修与神格化传统，隐世与宗教几乎一体 |
| 中亚北亚区 | 中亚草原、西伯利亚 | 地广人稀，萨满传统，维护难度最大的是面积 |

| 东欧北欧区 | 东欧平原、斯堪的纳维亚 | 血族领地所在，最古老的领主政治 |

总部隐世空间锚定在东亚一区昆仑山脉的灵脉节点上，行政上不属于任何维护区——它是"第十二区之外的房间"。

## 各区域隐世形态

**华夏**——最古老的连续传承。玄门宗门体系延续数千年未断，修真者是滤网工程当年的主要设计方（意识锚炼制用了修真者元神碎片）。昆仑总部设在华夏地界，给玄门带来超然声望——但织网者不属于玄门，这条界限华夏内部一直很清醒。皇甫医族是华夏修真家族东渡日本的典型分支。

**日本**——全球唯一的"共治实验场"。八大势力加上S.C.B分局构成复杂的均衡格局，风见市试点是公约签署以来最大胆的结构性试验。详见各势力档案。

**欧洲**——最古老的贵族政治。隐世被两套体系分治：教会圣职系统管"净化"，世俗结社管"共存"，血族在东欧保留了字面意义的领地，英伦妖精庭自成一国。欧洲历史上的猎巫浪潮是滤网区域性衰减酿成的恐慌标本——那些失控的猎杀年代大多对应着滤网衰减窗口，恐慌留下的疤痕让欧洲各派系对"暴露"二字有本能的忌惮。

**北美**——最年轻也最混乱。没有本土大妖传统，隐世是近两百年间从全世界漂过去的移民拼起来的：欧洲血族、亚洲狐族、非洲灵医、原住民精灵——谁都没有主场。唯一强势的是S.C.B美洲指挥部，装备最好、编制最大、最相信技术能解决一切。北美隐世的特点是"没有规矩"——这既是活力也是隐患。

**东南亚**——边界最薄的区域。雨林、水田、村落与精怪的共存从未真正中断过，当地人对"家里有看不见的住客"习以为常。滤网的翻译在这里反而偶尔显得多余——很多居民心里清楚得很，只是不说。治理形态极松散，巫师与灵媒构成事实上的基层秩序。

**南亚**——神格化最深的区域。强大异类被当作神明供奉了数千年，神庙体系本身就是隐世结构。滤网在南亚的工作最微妙：它不需要完全掩盖超自然，只需要让"神迹"显得可控。

**中东北非**——契约文明的隐世。镇尼与人类立约的传统比滤网古老得多，这里处理超自然关系的方式是"把一切都写进条款"。契约议会是隐世中最接近"法治"的治理形态。

**撒哈拉以南非洲**——口述传统的隐世。祖灵信仰体系庞大而分散，知识靠口传，档案不存在于纸面。这给S.C.B的情报工作造成了独特困难——你无法渗透一场没有文字的传承。

**南美大洋洲**——叠层最深的区域。殖民者带来的欧洲隐世叠在原住民灵境之上，两层从未真正融合。档案完整度全球最低——织网者对这一区的了解主要依赖意识锚的遥测数据。

## 昆仑公约

滤网工程完成之日，参与建造各方在昆仑总部签署了根本约章，后世称《昆仑公约》。公约不是组织，是一套各方承诺遵守的底线条款：滤网维持义务、辖区自治权、不干涉原则、试验区特许条款、违规制裁机制。S.C.B成立后在公约框架下获得"人类侧管理"的承认地位。详见《全球隐世公约》档案。

## 风见市的全球坐标

风见市是公约史上第一块"共存试验区"——公约特许条款第一次被实际启用。

全球都在看。亚太指挥部的关注最直白：试点的数据决定S.C.B未来百年的政策方向。玄门关注的是修真体系能否在"半公开"环境里运转。欧洲旧贵族们最关心试验区如果成功，他们领地上的"领民"会不会开始要求权利。北美指挥部的态度是"看数据但随时准备接管"——如果日本管不住，美洲乐意接手。

这种关注不是抽象的。各国势力派驻风见市的观察者、以各种身份渗透的情报员、用学术和商业名义常驻的眼睛——一个不到百万人口的日本小城，承载的超自然情报流量超过东京。铃这类间谍在风见市不是个案，是标配。

## 全球格局的张力

**滤网倒计时**。意识锚核心材料衰竭不可逆，滤网剩余寿命约四到五百年（阵眼保卫战后透承认实际数字更短）。各区域对"之后怎么办"的立场分裂严重：东亚倾向渐进过渡，欧洲领主们希望尽量拖延，北美主张加速技术替代方案，非洲和东南亚相当多声音认为"塌了就塌了，人本来就看得见"。

**灵气复苏**。2010年起全球灵气浓度回升，原因不明。各维护区的意识锚负荷随之上升，滤网衰减事件逐年增多。织网者内部有假说认为复苏与意识锚衰竭存在关联——灵脉在"试图修复"什么，但目前只是假说。

**数字层侵蚀**。摄像头分辨率和AI分析能力持续进步，滤网在数字空间的有效性逐年下降。北美指挥部认为"技术解"是出路，织网者认为靠技术堵是治标——双方的分歧已经公开化。

**评级错位**。各区域的威胁评估体系标准不一，同一个体在不同辖区可能差出两个等级。公约框架下这造成引渡、协防、资源共享上的持续摩擦。详见《威胁分级制度》档案。

**试验区赌注**。风见市的成败被各方解读为对未来路线的公投——成功则"渐进公开"路线获得最大论据，失败则"永远藏下去"派占上风。这让风见市的每一次局部危机都背着超出其规模的政治重量。
